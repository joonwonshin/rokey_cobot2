# Plan: C270 웹캠 활용 로드맵

**작성일:** 2026-08-03
**배경:** 보유 중인 C270 웹캠을 실제로 쓰고 싶다는 요청. `state.md` 확인 결과 **C270은 아직 한 번도 실기로 등록·실행된 적 없음** — D435i만 실기 검증 완료. 스프린트 계획서(`M0609_perception_motion_sprint_plan.md`)엔 관련 항목이 Day1/Day2/§6-1에 흩어져 있어 여기 순서대로 모은다.
**GPU 불필요** — 전부 CPU/USB 카메라 작업.

> 📁 문서 지도: [[ws/cobot2/README]] · 상태: **⏸ 미착수(2026-08-03 기준)**.
> D435i에서 걸린 좌표 규약·캘리브 함정은 [[ws/cobot2/context/constraints]]에 이미 있다 — 여기서 다시 겪지 말 것.

## 순서 (앞이 막히면 뒤로 안 내려감)

### 1. 노드 등록·동작 확인 (계획서 Day1 P1, 미착수)
```bash
sudo apt install ros-humble-v4l2-camera   # 또는 ros-humble-usb-cam (src/usb_cam이 이미 vendor로 있음)
v4l2-ctl --list-devices                   # C270 장치 노드(/dev/videoX) 확인, D435i와 겹치지 않는지
ros2 run v4l2_camera v4l2_camera_node --ros-args \
  -p video_device:="/dev/video2" \
  -p image_size:="[1280,720]" \
  -r image_raw:=/webcam/image_raw
ros2 topic hz /webcam/image_raw           # D435i 동시 구동 시 드랍 여부
```
**DoD:** `/webcam/image_raw`·`/webcam/camera_info` 정상 퍼블리시, D435i와 별도 USB 컨트롤러 연결 확인.
**주의:** `src/usb_cam`은 이미 저장소에 vendor로 들어 있지만 **이 ws에서 빌드/실행해본 적 없음** — 처음 돌릴 때 launch 인자·픽셀포맷부터 확인.

### 2. eye-in-hand 캘리브레이션 (계획서 Day2 P0-b, 미착수)
- 알고리즘 자체는 **합성 데이터로 검증 완료**(`handeye_calibration.py`, max|err| 1.1e-13) — 코드는 신뢰 가능, 실기 데이터만 없는 상태
- `corecode/Calibration_Tutorial/data_recording.py`에서 `USE_REALSENSE_TOPIC=False`, C270 장치번호 지정
- 저장소에 이미 있는 `T_gripper2camera.npy`는 **튜토리얼 잔재값**(z=-233mm) — 반드시 새로 찍어 덮어쓸 것
```bash
python3 handeye_calibration.py            # → T_gripper2camera.npy (TCP 기준, mm)
ros2 run m0609_rg2_bringup calib_npy_to_tf.py \
  corecode/Calibration_Tutorial/T_gripper2camera.npy link_6 camera_link_webcam
ros2 run tf2_ros tf2_echo link_6 camera_link_webcam
```
**DoD:** `link_6 → camera_link_webcam` 정적 TF 확보, `base_link → camera_link_webcam`(FK 자동 계산)이 `tf2_echo`로 확인됨.
**주의:** D435i에서 발견된 규약 버그(optical vs body frame, npy는 OpenCV optical 규약)가 여기도 그대로 적용됨 — `calib_npy_to_tf.py`가 보정하는지 재확인.

### 3. 역할: 근접 확인 / self-occlusion 폴백 (계획서 §6-1, GPU 불필요)
- D435i가 그립 직전 팔에 가려질 때(self-occlusion) C270로 보완 확인
- 가장 게으른 첫 버전: 그립 직전 프레임을 `/webcam/image_raw`에서 캡처해 사람이 육안 확인(rosbag 저장 or rqt_image_view) — 자동 판정 로직은 필요해질 때 추가
- 자동화가 필요해지면: 색상 기반 근접판정 정도로 시작(별도 학습·GPU 없이)
