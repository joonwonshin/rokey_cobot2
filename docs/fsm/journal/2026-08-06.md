(`isaac_ros-dev`만 마운트, 8분 전 기동)로 충분해 **재시작 없이 진행.**

- **`isaac_ros_nvblox` 빌드 성공** (27패키지, 0 실패, ~7분). 막힌 것 3개, 순서대로:
  1. NITROS 코어 레포(`isaac_ros_nitros` — `isaac_ros_managed_nitros`/`isaac_ros_gxf`/
     `*_nitros_image_type` 등을 담음)가 아예 클론이 안 되어 있었음 → `v3.2-14`로 클론.
  2. rosdep `magic_enum` 키 미해석 → `sudo apt install ros-humble-magic-enum`(apt엔 있었음, 컨테이너 내부).
  3. 🔴 **업스트림 CMakeLists 버그**: `isaac_ros_nitros`/`isaac_ros_nvblox` 레포 29개 파일이
     `magic_enum::magic_enum`을 링크하면서 `find_package(magic_enum)`을 빠뜨림 — apt 설치 후에도
     계속 막혀서 처음엔 rosdep 문제로 오인했다. 일괄 패치, `patches/isaac_ros_ni{tros,vblox}-cmake-magic_enum.patch`.
  상세는 [[ws/cobot2/isaac_ros_nvblox_setup]] §5-1.
- `warp-lang`을 1.5.0으로 재설치(컨테이너 재시작으로 1.16.0에 원복돼 있었음 — §2-3 재발).

  `/camera0/color/image_raw` 등 **드라이버+splitter가 컨테이너 안에서 같이 뜨는 걸 전제**한다.
  이 ws는 드라이버가 **호스트**에서 `/camera/camera/...`로 돌고 컨테이너는 구독만 하는 구조라

  직접 우리 토픽(`/camera/camera/aligned_depth_to_color/*`, `/camera/camera/color/*`)으로
